# Surge-module

个人 Surge 模块。

## Telegram 跳转

将 `t.me` / `telegram.me` 链接自动跳转到指定的 Telegram 客户端。

### 支持客户端

- Telegram
- Nagram
- Swiftgram
- Turrit
- iMe
- Nicegram
- Lingogram

### 安装

在 Surge 中添加模块：

https://raw.githubusercontent.com/X-IAUN/Surge-module/main/Telegram.sgmodule
使用
例如选择：
CLIENT = Swiftgram
即可自动跳转到 Swiftgram。
注意
模块需要 Surge 开启 MITM。
如果修改模块参数后没有生效，建议删除旧模块后重新添加 Raw 模块。
